# 21F2000709_MLOPS_WEEKLY_ASSIGNMENT

Week 9 Assignment

Objective:
Introduce a sensitive attribute into the IRIS dataset, detect bias with Fairlearn, explain model decisions using SHAP, and reason about drift monitoring and governance for production ML systems.


Utility of each file:
- main.ipynb - The notebook file containing all the code and markdowns related to assessing fairness using Fairlearn, generating SHAP Summary Plots and detecting data drift using evidently ai.

- modelcard.md - Summary file for the model including Model Details, Intended Use, Training Data Description, Performance Metrics, Model Explainability, Known Limitations & Risks.
